# Website Oficial & Mídia Kit • Associação de Vôlei BN (AVBN)

Site institucional moderno e mídia kit interativo de captação de patrocínios via Lei Federal de Incentivo ao Esporte (Processo nº **2504642** — R$ **353.095,11**).

---

## 🚀 Como Subir na Vercel (Em menos de 2 minutos)

### Opção 1: Via Vercel CLI no Terminal (Mais Rápido)
Abra o terminal dentro desta pasta e digite:
```bash
npx vercel
```
1. Faça login na sua conta da Vercel se solicitado.
2. Pressione `Enter` para confirmar as opções padrão.
3. Seu site estará online em segundos com URL oficial (`https://seu-projeto.vercel.app`)!

---

### Opção 2: Pelo Dashboard da Vercel (Sem Código)
1. Acesse [vercel.com](https://vercel.com) e entre na sua conta.
2. Clique em **"Add New..."** > **"Project"**.
3. Se você usa GitHub/GitLab, conecte seu repositório e clique em **Deploy**.
4. Se preferir subir a pasta localmente, você pode usar o comando `npx vercel` no terminal ou importar via CLI.
5. As configurações já estão 100% prontas em `vercel.json`!

---

## 📁 Estrutura de Arquivos Organizada
- `index.html`: Página única contínua, responsiva, com galeria touch, simulador de IR e lightbox tela cheia.
- `vercel.json`: Regras de roteamento estático, URLs limpas e cabeçalhos de cache otimizados.
- `package.json`: Metadados do projeto e scripts de verificação.
- `assets/`: 17 registros fotográficos oficiais em alta resolução, logo vetorizada e mídias de apoio.
- `server.js`: Servidor local opcional para testes em Node.js (`npm start`).
